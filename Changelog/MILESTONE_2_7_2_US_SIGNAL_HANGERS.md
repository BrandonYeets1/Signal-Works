# Milestone 2.7.2 — US-Style Signal Hangers

## Changes

- Traffic signals now search up to four blocks above for the nearest modular mast arm.
- A visible narrow drop tube spans any air gap between the mast and signal head.
- A width-matched saddle clamps around small, medium, or large mast arms.
- A lower collar, swivel box, and rear/top mounting tongue overlap the signal housing, eliminating visible gaps.
- Standard, pedestrian, doghouse, and five-section heads use the same mounting system.
- Inventory icons were not changed.

## Placement

Place a signal anywhere from one to four blocks below a mast-arm segment. The nearest mast directly above the signal receives the automatic hanger.

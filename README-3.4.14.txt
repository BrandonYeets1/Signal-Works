SIGNAL WORKS CORE 3.4.14 SOURCE PATCH

This patch is based on the uploaded src(2).zip baseline. Your PBR textures, Traffic Signal Ahead model, and new signal_works.png icon are intentionally not duplicated in this patch because they already exist in your source.

1. Extract this ZIP directly into the project folder containing build.gradle.
2. Run Apply-SignalWorks-3.4.14.bat.
3. Run gradlew.bat clean build.

The applicator is safe to rerun and removes only the known duplicate legacy texture folders and superseded icon/item-model files.
